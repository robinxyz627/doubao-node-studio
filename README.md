> 一个面向豆包 AI 视频生产的本地工作台。它不是另一个视频模型，而是让你更顺手地组织参考图、镜头提示词、生成任务与无水印成片的可视化工作流。

## 你可以用它做什么

| 场景 | 豆包节点台如何帮助你 |
| --- | --- |
| 做一条短片 | 在同一张画布上拆镜头、摆放人物/场景参考图，再分别生成每个镜头。 |
| 保持角色与场景一致 | 图片节点连入视频节点；提示词中用 `@图1`、`@图2` 精确指向视觉锚点。 |
| 管理反复生成的版本 | 一个视频节点可以保存多次生成结果，切换查看不同成片首帧。 |
| 使用多个已登录账号 | 为每个账号创建独立的本机 Chrome Profile，记录 Fast 成片额度并按可用额度分发。 |
| 收回成片 | 豆包页面返回结果后，工作台将任务状态、失败原因和可解析到的无水印原始成片回写到节点。 |

## 核心能力

### 无限画布，而不是表单堆叠

- 右键创建图片、文本、视频节点；也可直接把图片拖入画布。
- 中键平移画布、`Ctrl + 滚轮` 缩放、左键框选并整体移动。
- 节点通过连线表达素材与镜头关系；删除连线不会删除原素材。
- 视频节点日常保持简洁，选中后才展开提示词、比例、时长和提交控制。

### `@` 视觉锚点

- 视频节点只会列出已连入的图片；输入 `@` 即可选择并插入高亮引用。
- 文本节点可引用用户素材库中的所有图片，连到视频节点后会接管该视频的提示词。
- 提交前，`@图1` 会按连线顺序转换成豆包需要的“图 1 为…… / 图 2 为……”引用关系；素材文件名不会被塞进你的正文提示词。
- 鼠标悬浮在引用上可查看缩略图，方便检查自己写的锚点有没有指错图。

### 为 Seedance Fast 设计的镜头节点

- 默认模型为 **Seedance 2.0 Fast**，镜头时长可在 **4–10 秒**间调整，默认 10 秒。
- 比例支持豆包页面现有的自动、3:4、4:3、9:16、16:9、1:1、21:9；节点预览会平滑跟随比例变化。
- 一个镜头不必硬塞满 10 秒：你可以把后段作为后期可裁切的余量，或设计成可保留的延展动作。
- 提交、生成中、肖像保护未通过、内容审核未通过、生成失败、无水印下载等待与生成成功都会显示在视频节点和任务列表中。

### 浏览器桥接与本地账号容器

- 工作台通过本机 Chrome 扩展与**你已登录的豆包网页**协作；不会要求你把 Cookie 上传到服务器。
- 每次任务会新建豆包对话，避免前一个任务的上下文干扰下一条视频。
- 可创建多个账号容器：每个容器使用独立 Chrome Profile、独立登录态与每日额度记录。
- 任务会优先分配到有余量且桥接在线的账号。审核失败会释放临时占用；真正生成成功后才计入成片额度。

### 无水印成片回收

- 扩展会监听豆包页面的媒体信息，尝试解析平台已提供的原始媒体地址，并在页面内展示带首帧预览的候选成片。
- 你可明确选择要下载的成片；工作台任务完成后也会尝试将已解析的原始流保存到本地并回填视频节点。
- 豆包网页结构与媒体接口可能调整。若页面没有暴露可解析的原始地址，节点会保留“等待无水印成片”及具体诊断，而不会伪装成已下载。

## 从画布到成片

```text
图片 / 用户素材库  ─┐
文本节点（可选）    ├─> 视频节点 ─> 豆包网页桥接 ─> 任务状态 / 无水印成片
构图或导演台截图   ─┘
```

1. 建一个工程，把人物设定图、场景九宫格、构图参考拖进画布。
2. 将需要的图片连接到视频节点，在提示词里用 `@` 指明它们各自承担的人物、服化道、环境或构图锚定作用。
3. 选择比例与时长，点击节点中的小箭头提交。
4. 豆包网页端生成期间，视频节点会显示进度；完成、审核失败或下载异常都会回传到工作台。
5. 对同一镜头再次生成时，新结果可覆盖当前预览，也可通过节点顶部的版本切换回看历史成片。

## 快速开始

### 1. 下载并启动

前提：**Windows、Google Chrome、Node.js 20+**。

1. 从 [Releases](https://github.com/robinxyz627/doubao-node-studio/releases) 下载源码包，或直接克隆本仓库。
2. 双击 [`启动工作台.cmd`](启动工作台.cmd)。
3. 浏览器打开 <http://127.0.0.1:4318>。

### 2. 安装本机桥接扩展

1. 在工作台中打开“连接”，复制本机地址与配对密钥。
2. 在用于登录豆包的 Chrome 中打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本仓库的 [`bridge-extension`](bridge-extension) 文件夹。
4. 打开扩展弹窗，填入工作台地址与配对密钥；状态必须显示“已连接豆包页面”。

首次添加账号时，工作台会启动一个使用独立 Profile 的 Chrome 窗口。请在该窗口登录豆包并安装同一份桥接扩展。登录态只保存在对应的本机 Profile 内。

### 3. 开始做第一个镜头

右键画布创建图片节点和视频节点，上传或拖入图片后，将图片端口连到视频节点。选中视频节点，输入提示词，配置比例/时长并提交即可。

## 推荐搭配：AI Video Director Skill

节点台负责“做与管”；[AI Video Director Skill](https://github.com/robinxyz627/ai-video-director-skill) 负责“想与写”。它包含：

- 剧本拆解、拉片、导演思维与镜头语言；
- 90 秒短片的节奏与镜头预算；
- 写实横版角色设定图、场景九宫格、服化道与视觉锚定；
- 针对 10 秒镜头上限的提示词、对白节奏和后期拼接策略。

## 隐私与本地数据

首次运行后会自动创建以下本地目录：

| 目录 | 内容 |
| --- | --- |
| `data/` | 工程 JSON、上传素材副本、任务记录、下载成片、账号 Chrome Profile。 |
| `用户素材库/` | 可跨工程复用的人物、环境、物品、风格与提示词文本。 |
| `runtime/` | 本机使用的 Chrome for Testing 运行时（如已配置）。 |

这些目录均被 `.gitignore` 排除；本仓库和 Release **不包含**你的参考图、工程、生成视频、账号 Cookie 或浏览器 Profile。画布工程保存在本地服务端，而不是依赖浏览器缓存，因此可在同一台电脑的其他浏览器中继续打开。

## 使用边界

- 本项目只协调你自己的浏览器和豆包网页；生成额度、模型可用性与审核规则仍以豆包页面实际显示为准。
- 自动化依赖网页界面与扩展可访问的页面数据。网页改版、验证码、人机验证、网络休眠或平台策略调整都可能导致任务暂停，需要用户在豆包窗口中确认或重新连接。
- 请只使用你拥有权利的图片、视频、角色形象与提示词，并遵守适用的平台规则与法律。
